Workflow

  1. Source products from Korean suppliers
  2. Calculate per-market price (fees, FX, SLS shipping)
  3. Create / update listings on Shopee via Open API
  4. Sync stock & price daily
  5. Fulfil orders via Shopee SLS (KR warehouse)

APIs used

  • v2.shop.get_shop_info – shop profile
  • v2.product.get_item_list / get_item_base_info – listings
  • v2.product.add_item – new listings
  • v2.product.update_price – price sync
  • v2.product.update_stock – stock sync
  • v2.order.get_order_list / get_order_detail – orders
  • v2.logistics.* – SLS shipping documents

Buyer personal information is not requested; cross-border parcels ship to the Shopee KR warehouse.
